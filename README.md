## 📱 PhonePe Payment Insights Dashboard | Power BI

## 1. Project Title
**PhonePe Transaction & User Behavior Analysis Dashboard - Payment Insights, Powering Bharat**

## 2. Short Description / Purpose
This end-to-end Power BI project analyzes PhonePe's payment ecosystem to understand transaction performance, user demographics, and service usage.

I analyzed 300K+ transactions worth 3.47bn to uncover how, when, and who is using PhonePe the most.

## 3. Tech Stack Used to Build Dashboard
- **Power BI Desktop:** For dashboard designing & visualization
- **Power Query:** For data cleaning & removing duplicates
- **DAX:** For creating custom measures & KPIs
- **Data Modeling:** Relationship building between tables
- **Visuals:** Donut Chart, Area Chart, Bar Chart, KPI Cards, Slicers

## 4. Features / Key Highlights / Business Impact

#### A) KPI Cards:
- Total Transactions: 300K
- Total Transaction Value: 3.47bn
- Unique Users: 8.97%
- Successful Transactions: 108K

#### B) Key Insights from Dashboard:
- **Transactions Over Time:** Transactions peak in Mar, Jun, Sep
- **Age Segment Contribution:** Millennials (37.3%) and Gen X (37.4%) are core users
- **Weekday vs Weekend Usage:** 71.6% transactions happen on Weekdays
- **Service Analysis:** Loans contribute highest value (2bn)
- **Top 5 Users:** Identified for loyalty programs
